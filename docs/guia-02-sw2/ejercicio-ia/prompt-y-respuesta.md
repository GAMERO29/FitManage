# Ejercicio 5 · Escenarios de calidad pedidos a una IA

**Herramienta:** Claude (Anthropic), sesión de chat. **Fecha:** 30/10/2026.
**Datos enviados:** solo la descripción general del producto; ningún dato de socios.

## Prompt

> Redacta tres escenarios de calidad para FitManage, una aplicación web para que los gimnasios pequeños de Cúcuta gestionen membresías, pagos y la consulta de acceso en recepción.

## Respuesta de la IA (sin modificar)

> **1. Rendimiento:** El sistema debe responder rápidamente a las consultas de los socios, incluso en momentos de alta demanda, garantizando una experiencia de usuario fluida y sin interrupciones.
>
> **2. Seguridad:** Los datos personales y financieros de los socios deben estar protegidos mediante cifrado y mecanismos de autenticación robustos, de forma que solo el personal autorizado pueda acceder a ellos.
>
> **3. Disponibilidad:** El sistema debe estar disponible el 99,99 % del tiempo para que la recepción pueda operar sin interrupciones durante todo el horario del gimnasio.
