# ADR N.° 05 · Ningún contexto se distribuye: todos siguen en el monolito modular, con límites lógicos

| Campo | Contenido |
| --- | --- |
| Estado | Aceptado (30/10/2026) |
| Contexto | El mapa de contextos identifica 7 contextos delimitados (`docs/arquitectura/contextos.md`). La pregunta de la Guía 5 es si alguno justifica separarse en un servicio con su propia base de datos. Fuerzas: el driver número uno exige que un pago y su usuario, su socio y su auditoría se guarden en una sola transacción (QA-05); el internet de la recepción es inestable (R-03); el costo debe ser cero (R-01); y desarrolla una sola persona. |
| Alternativas consideradas | **A. Todo en el monolito modular** (estado actual). **B. Separar Reportes** como servicio de solo lectura con su propia base replicada. **C. Separar los 4 contextos con lógica propia** (Acceso, Socios, Membresías, Reportes) como funciones serverless con una base por servicio. |
| Decisión | Se mantiene A. Ningún contexto se distribuye. Los límites se respetan dentro del código: cada contexto es dueño de sus tablas y de su puerto, y la única copia distribuida de datos es la caché de solo lectura del navegador en Recepción, que existe por disponibilidad (QA-02) y no por moda. |
| Consecuencias | A favor: se conservan las transacciones ACID y las llaves foráneas que sostienen QA-05; no hay latencia de red entre contextos ni fallos parciales; el costo sigue en 0 USD. En contra: todo escala y se despliega junto, y un error grave en un módulo detiene la aplicación completa; se mitiga con el flujo `Calidad` y con respaldos diarios (RNF-07). |
| Análisis de costo operativo local | La alternativa C cuesta unos **94,08 USD al mes (≈ COP 299.655)** en AWS us-east-1: 4 bases RDS db.t4g.micro con 20 GB (55,92), NAT Gateway (32,89 entre horas y datos), IPv4 pública (3,65), Secrets Manager (1,60), y API Gateway y Lambda casi en 0 (`docs/guia-05-sw2/costos.py`). Para una MiPyme que vende 500 USD al mes con un margen del 20 %, eso es el 18,8 % de las ventas y el 94 % del margen. B costaría al menos una base adicional, y Reportes atiende a una sola persona, el dueño, unas pocas veces por semana. A cuesta 0 USD en la capa gratuita del PaaS. |
| Cuándo revisar esta decisión | Si FitManage atiende varias sedes con bases independientes, si Reportes empieza a frenar la consulta de recepción (QA-01 por encima de 2 s) o si aparece un equipo distinto a cargo de un contexto. |
