Primera versión etiquetada con versionamiento semántico: la línea base **LB-1** del 30/10/2026 (ADR N.° 01, `docs/linea-base-LB-1.md`).

- Núcleo de dominio en Python puro (RN-01 a RN-10) con 48 pruebas.
