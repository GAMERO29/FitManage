Cierre del proyecto integrador de Ingeniería de Software I y II (FPI-32). Primera versión con interfaz pública estable: el contrato `/api/v1` (`docs/api/openapi.yaml`) y la pantalla de recepción.

**Qué incluye**
- Pantalla de recepción: iniciar sesión, consultar el estado de un socio, registrar socios y pagos (ADR N.° 16).
- API `/api/v1` con JWT de acceso corto y renovación en cookie `HttpOnly` (ADR N.° 06), validada contra el contrato en cada respuesta y con Pact.
- Reglas de negocio RN-01 a RN-10 en un núcleo hexagonal, con PostgreSQL 16 e índice único para el comprobante (QA-05).
- Pipeline con nueve checks requeridos: pruebas (99 % de cobertura), contrato, SonarCloud, Semgrep, Trivy, secretos y licencias.
- Despliegue continuo a Render con healthcheck y rollback; OpenTelemetry, SLO de 99,5 % y runbook probado en simulacro.

**Por qué 1.0.0:** la API pública y la pantalla ya tienen un contrato estable y probado (SemVer 2.0.0, §5). Desde aquí, un cambio incompatible del contrato sube la versión mayor.

**Pendiente, sin rodeos:** la base gratuita de Render vence cerca del 2/12/2026 (H1); falta el aviso de privacidad antes de cargar socios reales (DT-10, H2); no hay pantalla para crear planes ni personal (DT-24). Detalle en `docs/Dossier_Final.md` y `docs/roadmap.md`.
